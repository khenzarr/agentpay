# AgentPay Final Brandkit (Sprint Integration)

## AgentPay brand direction

- **Selected direction:** Concept C — **AP Monogram**
- **Positioning:** `USDC-native settlement infrastructure for autonomous work.`
- **Personality:**
  - technical
  - premium
  - precise
  - trust-oriented
  - developer-friendly
  - Arc-native

This sprint integrates a **production-safe brand layer** using preview/public PNG assets while preserving product logic and claim-safe boundaries.

## Logo system

AgentPay’s logo system is centered around an **AP monogram** with a premium dark fintech visual style and cyan → blue → violet accent language.

- **AP monogram mark:** compact symbol for app/header and small-size usage
- **Horizontal lockup:** monogram + AgentPay wordmark for docs/README/social
- **Stacked lockup:** vertical arrangement for constrained/tall placements
- **App icon / favicon concept:** AP monogram in a high-contrast square container

### Background usage

- Primary: dark premium surfaces
- Light backgrounds are supported only with sufficient contrast treatment

> Note: current repo-integrated assets are **preview PNG boards**. True production vector exports (SVG/logo set) are intentionally deferred to a future brand production task.

- **Brand/display recommendation:** Satoshi (external, optional)

No font files are included in this sprint.

## Visual language

- dark command-center surfaces
- cyan/blue/violet gradient accents
- subtle glow (restrained)
- rounded cards
- rail/grid/infrastructure motifs
- trust + settlement + developer tools + stablecoin payments focus

## Usage rules

### Do

- Use logo on dark premium backgrounds
- Preserve clear space around logo
- Keep core gradient language intact
- Use AP monogram for small sizes
- Use full wordmark/lockup for README/OG/social contexts

### Do not

- Stretch or distort logo proportions
- Recolor arbitrarily
- Place on noisy low-contrast backgrounds
- Overuse high-intensity glow
- Imply unverified claims (mainnet/gasless/production) in brand copy
