# AgentPay Demo Readiness

**Date:** 2026-05-20

## Current status

AgentPay is ready for a public Arc Testnet demo focused on product behavior:

- create job
- parse `JobCreated`
- show `/jobs` and `/payments`
- show claim-safe integration boundaries

- USDC escrow on Arc Testnet
- ERC-8183 tutorial-subset lifecycle
- Event-driven UI from on-chain logs
- Optional ArcNS identity display/resolution

## Not claimed

- full ERC-8004 compliance
- paymaster / gasless support on Arc Testnet
